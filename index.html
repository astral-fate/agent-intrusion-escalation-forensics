Methodology

A manuscript that cannot contradict its own artifacts

Provenance with the data

Every source carries its SHA-256 and evidential class. A revision upstream shows up as a digest mismatch.

Parsers halt, never guess

A partial parse looks plausible. Each stage asserts a reconciliation and stops if it fails.

No number typed by hand

The manuscript is a template. All 61 quantities are recomputed at build; an unknown one fails the build.

  • Density restriction. An envelope is not a duty cycle, so inference is limited to the three phases above 1,000 actions.
  • The bound comes first. We compute what the statistic could have reported before reporting it.
  • Honest boundary. This buys consistency with the sources, not correctness of the measure.

Conclusion

Nobody measures the step from verdict to interrupt

What the record establishes

Detection was not the binding constraint at either organisation.

What we propose

EMR — an escalation-miss rate, with an annotation that transfers between deployments.

What we release

Corpus, pipeline and harness, so the measurement runs on the next record.

Limits. One campaign, n = 1. No value of EMR is claimed here — the victim's escalation policy is unpublished, so the metric is an instrument, not a measurement. Two timeline dates rest on press reporting and every interval using them is flagged.
